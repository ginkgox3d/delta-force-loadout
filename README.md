# GINKGO Loadout — Delta Force Database

Web katalog loadout Garena Delta Force berbasis React + Vite. Versi ini sudah dipoles dengan visual dark tactical, glassmorphism, responsive card grid, preview screenshot, pagination, search, filter mode/kategori, dan bilingual ID/EN.

## Jalankan lokal

```bash
npm install
npm run dev
```

## Build production

```bash
npm run build
npm run preview
```

Folder `dist/` sudah ikut disertakan sebagai hasil build production terbaru.
